A WordPress plugin for coaches, course creators, and digital subscription businesses managing tiered membership access. Features content dripping by membership level, role-based page restriction, recurring subscription billing via Stripe and PayPal, member portal with profile and billing management, automatic account suspension on payment failure with grace period recovery flows, and team or group subscription licenses for B2B customers. Reduces churn through automated dunning email sequences.

== Description ==

A WordPress plugin for coaches, course creators, and digital subscription businesses managing tiered membership access. Features content dripping by membership level, role-based page restriction, recurring subscription billing via Stripe and PayPal, member portal with profile and billing management, automatic account suspension on payment failure with grace period recovery flows, and team or group subscription licenses for B2B customers. Reduces churn through automated dunning email sequences.

**Features:**

* Core functionality

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate via WordPress admin > Plugins
3. Configure via Settings > WordPress Membership Site and Digital Subscription Management Plugin
